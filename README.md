# Knowledge Atlas · 3D

Локальный трёхмерный семантический атлас транзактного анализа. Обновлён существующий проект `knowledge-atlas-v2`: **37 понятий и 59 отношений** сохранены без добавления демонстрационных связей.

## Открыть приложение

Адрес: **http://127.0.0.1:5174/**. В меню Ubuntu — **Knowledge Atlas**. Ярлык и `start.sh` продолжают работать с этим же проектом. Скрипт сам запускает сервер и открывает браузер; интернет для повседневной работы не требуется.

Автоматический запуск без открытия браузера: `npm start` или `./start.sh --no-open`. При отсутствии зависимостей скрипт выполняет `npm ci`. Нужны Node.js 22+ и браузер с WebGL2. Сервер слушает только `127.0.0.1`. Лог — `.runtime/server.log`.

## Исследование

- **ЛКМ + движение:** вращение камеры вокруг графа. **ПКМ + движение:** сдвиг. **Колесо:** приближение; кнопки `+` и `−` также управляют масштабом. Автоматического вращения нет.
- **Выбор:** нажмите сферу, её подпись или результат поиска. Камера плавно фокусируется на понятии, соседи выделяются, остальная сеть приглушается.
- **Карточка:** определение, раздел, PageRank, полный список входящих и исходящих отношений, источник и строка CSV. Нажатие типа связи открывает её тройку; нажатие соседнего понятия продолжает исследование.
- **Окружение:** при выборе понятия открывается временная семантическая раскладка: источники входящих отношений слева, цели исходящих справа; соседние понятия собраны по типу отношения. Кнопка глубины добавляет второй шаг в задний слой (z). Глобальная раскладка при этом не перезаписывается и точно восстанавливается при возврате. «Все соседи в кадре» вписывает выбранное окружение. При близком фокусе дальние соседи могут находиться за краем экрана — список отношений всегда доступен.
- **Возврат:** «Назад», «Вперёд» и цепочка внизу сохраняют путь исследования. «Вся карта» возвращает исходный ракурс, снимает выбор и фильтр группы. Фильтры отношений сохраняются.
- **Группировка:** «Разделы» — содержательная классификация исходного набора. «Сообщества» — результат Louvain по структуре связей. Перестройка проходит в настоящем 3D; выбранное понятие сохраняется.
- **Фильтры:** статус отношения, конкретный тип отношения и группа. Метрики рассчитаны на полной сети, фильтры меняют только видимость.
- **Подписи:** уровень детализации зависит от расстояния камеры. Подписи отношений появляются только в контексте выбранного понятия/связи или наведения. Экранные прямоугольники проверяются на пересечения между собой и с проекциями узлов. Подпись, которой не хватает места, скрывается; полный список доступен в карточке. При наведении приоритет подписи повышается.
- `/` открывает поиск, Enter выбирает первый результат, Escape возвращает общую карту.

Цвет сфер обозначает текущую группировку. Радиус связан с PageRank. Стрелки показывают направление Source → Target. Цвет выделенной связи: голубой — теоретическая, бирюзовый — методическая, охра — аналитическая; выбранная связь подсвечивается золотым.

## Архитектура и сохранение координат

- **Three.js 0.186.1**: WebGL2, PerspectiveCamera, реальные сферы, стрелки, объёмные оболочки областей и OrbitControls.
- **3d-force-graph 1.80.1**: отображение графа, raycasting для выбора объектов, камера, интерфейс к физическому движку.
- **d3-force-3d 3.0.6**: 3D-симуляция с силами связей, отталкивания, предотвращения столкновений и притяжения по x/y/z. Для разделов и сообществ строятся отдельные конфигурации.
- **Graphology 0.26.0**, **Louvain 2.0.2**, **graphology-metrics 2.4.2 / PageRank**: направленная семантическая модель и анализ.
- **Vite / Node.js**: локальный сервер и production-сборка.

Начальная физическая модель рассчитывается детерминированно с фиксированным генератором случайных чисел и стабилизируется до показа. Узлы имеют независимые x/y/z; это не плоская карта, наклонённая в перспективе. При смене группировки физика 3d-force-graph движет узлы к другой конфигурации и после стабилизации фиксирует позиции.

Координаты обеих группировок сохраняются в `localStorage` текущего браузера. Ключ содержит версию алгоритма и отпечаток всей семантической модели, поэтому смена данных инвалидирует старую раскладку. После перезагрузки используются сохранённые позиции. При недоступности хранилища остаётся воспроизводимая начальная компоновка. Кнопка **«↓ Координаты»** скачивает JSON с обеими раскладками; автоматической записи координат на диск и загрузки этого JSON через интерфейс нет.

Основные файлы: `src/model.js` — Graphology и детерминированная физическая модель; `src/scene.js` — Three.js/3d-force-graph, сохранение позиций и размещение подписей; `src/main.js` — семантическое исследование, фильтры и карточки.

## Исходные данные и резервные копии

`public/atlas.json` — существующая нормализованная семантическая модель. Для узлов сохранены определения, разделы и происхождение; для отношений — исходное название, источник, цель, вес, статус, файл и строка.

`originals/2026-10-24/` содержит исходные CSV, GEXF и первоначальный Cytoscape-проект. `originals/comparison.json` содержит SHA-256 и сравнение исходных файлов. Перед заменой 2D на 3D сохранена полная копия исходников, данных, зависимостей и тестов в **`originals/before-3d-20261024-181154/`**. Обе предыдущие реализации доступны для восстановления.

CSV-копии побайтово совпадают. В GEXF совпадают 37 идентификаторов/названий и 59 троек отношений. **GEXF объявляет отношения ненаправленными; рабочие стрелки интерпретируют порядок Source → Target CSV.** Это допущение осталось явно обозначено в интерфейсе. Научная верификация определений и связей по книгам Берна не выполнялась; библиографических страниц в исходниках нет.

PageRank характеризует положение понятия в этой конкретной сети и зависит от интерпретации направления; это не мера теоретической истинности или абсолютной значимости. Пространственные расстояния — результат физической компоновки и группирующих ограничений, а не количественная мера смысловой близости.

## Проверка

- `npm run build` — production-сборка.
- `npm test` — Playwright, восемь тестов. Конфигурация самостоятельно поднимает dev-сервер, если порт свободен; работающий экземпляр повторно используется.
- `npm run test:production` — отдельная проверка готовой сборки через локальный preview.

Использован установленный Chromium; если найден `/home/anton/.cache/ms-playwright/chromium-1228/chrome-linux64/chrome`, конфигурация выбирает его. На другом компьютере — `npx playwright install chromium`.

Тесты проверяют 37/59 и исходные тройки, PageRank/Louvain, детерминизм обеих раскладок, изменение каждой из трёх координат и неплоский тетраэдр, PerspectiveCamera, WebGL-canvas, вращение и сдвиг камеры реальными событиями мыши, колесо над подписями, выбор сферы raycasting, восстановление координат после перезагрузки, фокусировку, подсветку соседей, подписи без пересечений, историю, глубину 2, поиск, фильтры и сохранение выбора при физической перегруппировке. Отдельно проверяются «Взрослый», «Трансакция», «Психологические игры», адаптивность и управление клавиатурой. Отслеживаются ошибки JavaScript, console.error и HTTP 4xx/5xx.

Скриншоты и отчёт — `artifacts/3d-*`. Визуально просмотрены общий вид, повёрнутая сцена, три исследуемых понятия и Louvain. Тестовый Chromium использует программный WebGL SwiftShader: функциональность настоящего WebGL проверена, производительность GPU пользователя не измерялась.

## Ограничения

Нет редактора и импорта теорий через интерфейс, библиографической базы, серверной БД и сохранения истории между сеансами. Координаты хранятся отдельно в каждом браузере; очистка хранилища возвращает детерминированную начальную модель. Перекрытие самих трёхмерных объектов в отдельных ракурсах возможно — это разрешается поворотом камеры; защита от пересечений относится к показанным подписям. В близком фокусе дальние соседи могут оказаться вне кадра; предусмотрено вписывание окружения. Проверена исходная сеть из 37 узлов; масштабирование до тысяч узлов не измерялось.

## Постоянные правила и содержательная проверка

`AGENTS.md` в корне задаёт обязательный цикл разработки и самооценки. Результат не принимается только по сборке и отсутствию ошибок. Отчёты с оценками и скриншотами сохраняются в `artifacts/qa/`.

После содержательной проверки 24 октября 2026 года исследование переработано: временная раскладка кодирует направление по горизонтали, одинаковые отношения группируются с точным количеством рёбер, второй порядок лежит в глубине. Положение внутри слоя задаётся ограниченной d3-force-3d моделью. Это условные координаты интерфейса, не научно измеренная близость понятий. На общей карте показаны несколько агрегатов межраздельных отношений с явно указанными разделами-источниками и разделами-целями. Они учитывают фильтры.

В исходном ракурсе локального исследования входящие слева, исходящие справа; после вращения камеры ориентируйтесь на стрелки. Одинаковая подпись с числом рёбер обозначает несколько исходных связей, не новую связь и не новое понятие. Полные тройки и переходы находятся в карточке; нажатие групповой подписи открывает одну из исходных связей.

Дополнительные проверки контролируют видимость всех прямых соседей и групп отношений для трёх проверяемых понятий на экране 1600×1000, их нахождение внутри кадра, направления по x и второй шаг по z, отсутствие изменения общей раскладки. На узких экранах и при произвольном ракурсе часть подписей может скрываться; карточка остаётся полной. Для общего обзора выбираются до четырёх наиболее многочисленных агрегатов; проверка пересечений может скрыть часть из них. Это не полный перечень межраздельных связей.
